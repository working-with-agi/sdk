# 要望一覧（依頼者から繰り返し確認されるもの）

このサンプル群への依頼者の要望を、作業のたびに見返せるよう記録します。

### 60. エンジンごとの計画ボード（ガント）を製品の中心に据える ✅
- 竹内さん：「欲しいのはこれだけど、これをメインに据えて考えてください」（エンジンごとの予定図）
- 対応：経営サマリー（レベル 1）の結論 3 行の直下にボードを常設。製品説明資料をボード中心（読み方／4 操作：動かす・変える・決める・固定する／各画面はボードを動かす判断材料）に再構成。
- 残り：ボード上で直接操作（ドラッグで時期変更、整備範囲の切替）し、その場で余力・予算・期限が再計算される GUI は未実装。

### 61. ボードは「動かす GUI」ではなく「シナリオ地図」で ✅（方針）
- 竹内さん：「動かすよりかは、シナリオ複数組んでおいて、それはこれの中みたいなカタチでマッピングするのが良いのでは？」「リアルタイムで全部計算するのは無理だし」
- 方針：前提（4 世界）× 打ち手（時期・整備範囲・工場）の板を年 1 回と月次で事前計算し、今の実績がどの板の中にいるかを 1 枚の地図に置く。ドラッグ即時再計算は作らない。
- 対応：製品説明資料の操作モデル（選ぶ・変える・決める・固定する）と次の一歩に反映。追跡（どの計画案に沿っているか）はこの地図の一部になる。実装は別担当で。

### 62. システムを使うタイミングを明示 ✅
- 竹内さん：「システムの使うタイミング、年間計画作成、月次検証」
- 対応：製品説明資料に年間カレンダー（年間計画作成 7〜9 月／予算要求 10〜12 月／月次検証 毎月／随時）を追加。

### 63. 問題の相互作用と、解消後に移るボトルネック ✅（資料）
- 竹内さん：「問題の相互作用も含めよう。これが解消することにより、何がボトルネックになると思いますか？…例としては工場の逼迫率」
- 対応：製品説明資料に 2 枚追加。連鎖 A（工期→余力→リース→予算超過）／B（判断の遅さ→枠・キット→先送り→混雑）／C（資料づくり→会議時間→判断の遅さ）。解消後の移動：資料準備の時間 → 工場の逼迫率（判断早期化が枠の取り合いを早める）→ 部品・キット納期 → 会議の処理能力。各段の備えを併記。
- 残り：この移動をモデルで検証する（判断リードタイムを短縮したシナリオで、工場負荷と booking race がどう動くかを invest.booking_game / track で数値化）。

- 対応：`cpd.py`、`track.py`（actuals に週次の先行指標 3 系列、`cpd` ブロック、着地 p80 と予備費）、`roll.py`（変化点後のリセット）、レポートの「変化点と前提の整合」カードと画面。結果は README の節に。
- 残り：EGT 傾き変化（A.5）。先行指標の系列は仮定（出典なし）なので、実データでは工場・サプライヤーの回答ログが要る。

### 65. 複数機種を含めて最適化 ✅（第 1 段）
- 竹内さん：「さらに複数機体を含めて最適化して」
- 対応：companies.json に会社ごとの追加機種（JAL：787/GEnx-1B、767/CF6-80C2。ANA：787/Trent 1000、767/CF6-80C2。前提は出典なし）。company.py が機種ごとの fleet/shops を作り（`--all-fleets`）、baseline.py が機種ごとに凍結、`multi.py` が会社全体で (1) 年度予算を 1 つの枠として機種ごとに ×0.9／×1.0／×1.1 で解き直し、期待費用＋欠航費用が最小の配分を選ぶ、(2) 全機種の着地を合算した幅と超過確率、(3) 判断期限の機種横断の負荷を出す。レポートに「機種横断（会社全体）」の画面。

### 67. 立て直しが安くなる計画法（理論化と分離表示）✅
- 竹内さん：「トラブルが起こった時に、リカバリーが安くなるための計画法などもありますか？ちゃんとそれの理論化できてます？それぞれの機能がどちら側か分類して」
- 理論：2 段階確率計画（リカース付き）。対策は ①起きにくくする（予防）②起きても痛くない（頑健・CVaR・安全在庫）③起きたら安く立て直す（リカース・リアルオプション・柔軟性）④早く気づく（逐次検知・情報の価値）の 4 側。README に機能の分類表。
- 対応：`evaluate.py` が費用を「計画どおり（見積もり・輸送・予備・固定費）」と「立て直し（所見・為替の超過、故障の割増、リース、代替、欠航、緊急キット）」に分け、`summary.py` の diff が打ち手ごとに保険料（先に増える分）と払い戻し（立て直しの減り）を出す。追跡に「遅れの費用」曲線。レポート「立て直しの安さ」画面。
- 発見（合成データ）：JAL 基準計画の立て直し費は 36.8 M$（全体の 17%、悪い 1 割で 85 M$）で、9 割が所見・為替の超過。予備・プール契約の払い戻しは基準世界ではほぼ 0（保険料だけ）。立て直しを安くする最大のてこは予備ではなく契約形態（固定価格・超過の分担率）と所見の見積もり精度。
