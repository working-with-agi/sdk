## 根拠の弱い数字
1. 「配分の規則」の値が章ごとに違うセルを指している。2 章（L31）・4 章（L49）・`linear_world.how` は「両社とも移した状態（配分の規則で移す場合）」= `move/move`。66% ではこのセルの二社の合計 −252.7 が四つのうち最悪。一方で 3 章（L43）と `fleet/politics.json` の `after.raw.linear_rule.airline = 66.6`（`number_notes`：「取り合いの目減りを避けた分（二社の合計、66% の場合）」）は、合計が最大の `stay/stay`（−67.7）を均衡（−134.3）と比べた値。同じ「規則」が、4 章では A の −114.5 を、8 章では +66.6 の利益を生んでいる。→ 規則が何を決めるのか（誰が移すか、移さないか）を一つに決め、そのセルで 2・4・8 章を揃えるべき。
2. 8 章の配分の規則の点数（`linear_rule.airline` 0.7）は二社の合計の値で、ほかの手の `airline`（`data/politics.json` の基準は「億円/年（会社 A）」）と単位が違う。`regional` の +1 も no_source。安全保障と環境で上位 3 に入る（L100, L102, L107）理由の一部はここにある。→ 会社 A だけの値に直すか、軸の注記に「二社の合計」を出し、その場合の順位も示す。
3. 財政規律の「伊丹を縮める、95%」（L106）→ `after.raw.itami_shrink.public = 4373` は「跡地の中央値 − 関西・神戸の手当ての中央値」（5,422 − 1,049）で、5 章の表で確率を 46% から 20% に下げた「造成費・地価の下落」の段（`itami_smaller.monte_carlo.steps[3]`）が入っていない。しかもこの 4,373 が `scale.public` そのものなので、伊丹を縮める手は公費の軸で必ず +2.0 になる。一位なのは物差しの決め方による面が大きい。→ 造成費を引いた値で公費を置き直し、95% が残るかを示す。
4. 「数値の軸は前と後で同じ物差しにそろえた」（L93）→ その物差し（`scale.public = 4373`、`scale.user_cost = 421`、`scale.airline = 190.7`）は、リニアの後にしかない手（伊丹を縮める、後の羽田＋対向空港）で決まっている。そのため前の世界では公費の点数が小さく圧縮され、`before.scores.hnd_dest.airline` は 2.06 で、`assumptions.how` の「−2〜+2」を超える。→ 「物差しはリニアの後の手で決まり、前の世界の公費の差は小さく見える」と注記する。

## 抜けている別の説明・反論
1. 時点のずれ：モデルは FY2030 の需要・機材（L3）に、2045 年に近畿圏まで開業する前提の 2010 年の予測（L25, L121）を当てている。開業は早くても 2037 年（`data/corridor.json` の `timeline.linear_osaka`）。開業時の需要・機材・枠は FY2030 と違う。L121 は予測の前提を書いているが、モデルの年度とずれていることは書いていない。
2. 拡張の価値が残るのは、取り分を移すからという説明：L124 が「多くは他社から移る取り分」と認めているのに、0 章（L11）と 8 章（L104）はその値を「拡張の価値」として主義の比較に使っている。業界全体では、価値の大部分が相殺される可能性がある。`share_model.alpha=1` も no_source（`data/hnd_slots.json`）。
3. 相手の動き：他社が移す先と往復数（新千歳 +3・福岡 +2・那覇 +6）は no_source（`data/corridor.json` の `rival_moves_to`）。ゲームの結果は、ここが変わると変わりうる。頑健さの 6 通りで変えたのは会社 B の運航費と運賃だけで、この値は振っていない。
4. 主義の「変化」の大部分は、手が新しく増えただけ：前の世界には三つの手がない（L93）。環境の上位 3 から外れた `slot_gain`・`fare_hold` は、点数が変わったのではなく、新しい手に抜かれただけ（`change.environment.dropped`）。0 章 L15 の「主義ごとの答えも変わる」は、リニアで価値の判断が変わったように読める。「選べる手が増えた結果」と書くべき。
5. 「後で外す手（赤線）」の列（L95〜L102）には、前からすでに外れていた手が混じっている。地方の「運賃（市場全体）」、財政規律の「羽田＋対向空港」、安全保障の「運用の見直し」は `before.isms.*.excluded` にもある。リニアで新しく外れた手と区別が必要。

## 読み手ごとの引っかかり
- 査読者：結論が便数の比率の置き方（α=1、no_source）、他社の移し先（no_source）、FY2030 と 2045 年前提のずれに依存している。感度が示されているのは会社 B の費用と運賃だけ。
- 経営者：「A は 110〜115 億円減る」は一つのセルの値。自社が移すか、相手が移すかで 26〜163 億円まで動くことが要約から読み取れず、配分の規則が自社にとって得か損かもわからない（66% では規則のセルが A にとってほぼ最悪）。
- 整備計画の担当者：767 の稼働倍率 1.106 は基準の年で上限に当たっている（`capacity_jal.json` の 767 の `at_util_cap: true`）。下がり幅 2〜7 億円は上限からの戻りを含む。9 章の「767 の退役の見直し」（L117）には、退役の時期を扱った出力がない。
- 反対論者：羽田 +20 往復の 119 億円は、伊丹の取り分を他社から取り戻す値で説明できる。リニアの後も羽田の拡張が要る根拠にはならない。財政規律の一位は、公費の物差しを伊丹が決めていることで説明できる。
- 初めての読者：「均衡」「キャップ」「対向空港」「差し引き」は 0 章に説明なしで出る（均衡は L43 で初めて説明）。0 章の 9%・66% と、3 章の「66%」（残る割合）が同じ記号で別の量を指していて紛らわしい。
