# 需要から何機・何基要るか — `fleet_from_demand.py` の結果と、連載側への回答

すべて合成データ（出所のない前提は `no_source`）。基準月は 2026-10（t=0）、24 か月。搭乗率の目標 0.85、為替 157 円/$。

## 1. 出るもの

`fleet/jal.json`・`fleet/ana.json`。`demand_rpk_737`（月ごとの需要の帯 p10/p50/p90）→ `aircraft`（要る機数、点検で止まる機、余り、p90 で足りない月、全機が飛んだときの搭乗率）→ `engines`（飛ぶ機 × 2 ＋ 予備 ＋ 見張りの短期リース、保有との余力）→ `levers`（足りない月の打ち手 4 つと費用、余る月の維持費）→ `planning_season`（年度の始まりに固める数字）→ `long_view`（20 年、退役後の機数と需要）→ `consistency`（737 シェアが機材と整合するか）。

## 2. 年度の始まりに固める数字

| | JAL グループ（56 機） | ANA（39 機） |
|---|---|---|
| FY2027 要る機数 p50 最大 ／ p90 最大 | 50.1 ／ 53.8 | 44.9 ／ 48.1 |
| p90 で足りない月 | FY2028-08 のみ（0.3 機） | FY2026 の 5 か月、FY2027 は 11 か月 |
| 逼迫月（2027-08）全機が飛ぶときの搭乗率 | 0.759 | 0.981 |
| 逼迫月のエンジン余力 p50 ／ p90 | 19 ／ 13 基 | 5 ／ 5 基 |
| 平年の整備費 | 266.8 億円/年 | 150.0 億円/年 |
| 需要の伸び +3.8% による増分 | +10.1 億円/年 | +5.7 億円/年 |
| 逼迫月の増便（growth_plan） | +1 機、+2.65 億円、縛りはエンジン | 0 機（縛りはエンジン） |
| 窓の動き（plan_from_demand） | 期限内 40→41 基、前倒し 11、平均 −1.0 か月 | 変化なし |
| 737 シェアの整合 | 整合 | **不整合**（整合するシェアは 0.234） |

ANA の「足りない月」は需要が本当に多いのではなく、737 シェア 0.28（no_source）が 39 機に対して大きすぎることの現れ。全機が飛んでも搭乗率 98〜102% が要る月があるので、連載でこの会社を扱うなら、シェアを「仮定」として明示したうえで 0.23 前後で引き直すのが筋。JAL は 56 機で余力 6〜12 機、20 年の長期では FY2028 から退役が需要を下回る（置き換え機は含めていない）。

## 3. 連載側の問いへの回答

1. **機数の基準は 56 か 28 か。** 56 が全体（JAL・JTA の 737-800、`companies.json`）。28 は国内幹線だけを見た部分集合で、会社の RPK に 737 シェア 0.33 を掛けると飛ぶ機は約 49〜50 機になるので、全体の 56 で語るのが整合する。28 を使うなら「幹線分だけ」と明示する。
2. **出所のない前提。** 737 シェア（0.33／0.28）、搭乗率の目標 0.85、単価 15 円/RPK、ウェットリース 850 k$/機・月、ドライリース 250 k$/機・月、帯の幅（残差の標準偏差 ＋ 年 2%×√年）。連載ではすべて「仮定」と書く。JSON の `assumptions` に列挙。
3. **JAL の欠けている月（2025-09〜12）。** 市場の季節指数 × 会社シェアで補っている（`missing_months`）。実データが入れば置き換わる。
4. **見送り（スピル）の下限。** 「乗せられない需要 × 搭乗率 × 単価」は下限として扱ってよい（乗り継ぎや翌便への移り替えを含めない）。連載では「少なくとも」と書く。
5. **月の数え方。** t=0 が 2026-10。4 月は t=6、8 月は t=10。年度は 4 月始まり（FY2026 は 2026-10〜2027-03 の 6 か月分）。
6. **引き継ぎ（roll）の数字。** `review/jal.json` の 160,099 → 216,208 k$（157 円/$ で 251 → 339 億円）が現行の正。
7. **0.35% の分母。** 年間の整備費 165.6 M$ ≈ 260 億円（`spend_per_year_k`）なら 2 年で ≈ 520 億円、0.35% ≈ 1.8 億円。請求ベース（257 億円）で割るなら 0.9 億円。連載ではどちらの分母かを添えて両方書く。
8. **連載の数字（搭乗率 93%、エンジン 1.4 基不足、増便 −4.2 億円）。** この計算の `planning_season.peak_month` と突き合わせる。JAL では逼迫月の搭乗率 0.76、エンジン不足 0（余力 13 基）、増便は +1 機で +2.65 億円なので、連載の数字は ANA 側の逼迫（搭乗率 0.98、余力 5 基）に近い。どちらの会社の話かを決めてから、こちらの値に合わせる。

## 4. 実行

```bash
python3 fleet_from_demand.py jal --out fleet/jal.json      # ana も同じ
python3 -m unittest tests.test_fleet_from_demand          # 8 件
```

`run_all.sh` は growth の後に呼び、`fleet/` に写す。
